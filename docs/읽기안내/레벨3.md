## 실제 5차 복구·6차 진단·7차 고정 모델

실행 전 원본·분할·로컬 초기 가중치와 설정 예제를 준비해야 합니다.

공개 7차의 config.example.json에는 사적 자료 경로와 manifestSHA가 없습니다.

자신의 자료로 기준을 채우고 prepare에서 고정 입력 SHA를 확인한 뒤 감독 진입 점을 사용합니다.

이미 학습한 상태에서 prepare/smoke를 다시 실행하지 않습니다.

기존 공개 1~5차와 실제 실험 번호는 다른 축입니다.

공개 3차는 학습 2차의 특징 그림 소프트웨어, 공개 4차는 로컬 3차의 선택 화면 수리, 공개 5차는 실제 4차의 고정 100회 코드입니다.

기존 번호·원문은 보존하고 실제 5차 복구를 별도 이름으로 추가했습니다.

실제 3차는 새 학습 실험이 아니라 학습 2차의 화면 수리라는 뜻입니다.

실제 6차는 기존 5차 모델과 같은 test 164장을 읽은 탐색 진단이고, 실제 7차는 새 ImageNet 초기값으로 시작한 별도 실험입니다.

2026-11-20 공개 기록 시점에 7차는 학습 진행 중이며 최종 시험 결과는 미측정입니다.

6차 수치를 7차의 빈 결과에 채우지 않습니다.

[6차의 집계 원비율](../../Conv1%20%EB%B8%94%EB%9F%AC%20OK-NG%20%EC%8B%A4%ED%97%98/6%EC%B0%A8/%EA%B2%B0%EA%B3%BC/%EC%A7%91%EA%B3%84_%EC%9B%90%EA%B0%92.json)에서는 분모와 정답 수를 함께 확인합니다.

백분율 요약은 소수 첫째 자리 반올림이며 원비율을 바꾸지 않습니다.

원영상·영상별 목록·가중치·운영 기록은 공개하지 않습니다.

<a id="guide-intro"></a>

## 프로젝트 소개

원고·노트북·저장 결과·대시보드를 차수별로 읽습니다.

과거 논문의 보고값과 현재 Conv1 실행 결과를 합치지 않습니다.

재현에는 원영상·분할·설정·결과 계보가 필요하며 의료 원자료는 공개하지 않습니다.


<a id="guide-problem"></a>

## 문제와 주요 기능

| 확인 대상 | 설명 |
| --- | --- |
| 라벨·분할 | 라벨 매핑과 원본 분할을 먼저 확인합니다. |
| 학습 증강 | 증강은 학습에만 적용하고 검증·시험 원본과 구분합니다. |
| source_class 의미 | source_class는 원본 범주 폴더 라벨이며 환자·병원·스캐너 식별자가 아닙니다. |

## LEVEL 3·실제 8차·독립 학습과 제안 점수

공개 코드는 자신의 비공개 입력과 고정 기준을 준비해야 실행할 수 있습니다. 설정 예제는 원본 영상·분할 manifest·가중치·실제 운영 경로를 포함하지 않습니다.

| 차수 | 동작·현재 결과 | 자료 · 상세 · 직전 비교 |
| --- | --- | --- |
| 실제 8차 | 열 강도 각각 100회 → 분류·공격 완료 → 다음 강도. σ0 학습 중·분류 성적과 점수 미측정 | [자료](../../Conv1%20%EB%B8%94%EB%9F%AC%20OK-NG%20%EC%8B%A4%ED%97%98/8%EC%B0%A8) · [상세](../../docs/revisions/conv1-okng-round8.md#user-content-reading-level-3) · [직전 비교](../../docs/revision-diffs/conv1-okng-round8.md) |

백분율과 100점 점수의 요약은 소수 첫째 자리 반올림입니다.

점수 98.85는 98.9로 표시하되 원 점수 98.85는 펼쳐 확인합니다.

정확도는 정답 수/분모와 원비율을 함께 확인하여 반올림 100.0%와 실제 전부 정답을 구분합니다.

점수는 원값·G·T_attack·T_prior·동 점 분포·정확 반환 그룹 수·잔여 분포를 같이 읽습니다.

공개 파일에 실제 CT 결과나 그림이 없다는 점과 자신의 실행에서 생성되는 비공개 결과를 구분해야 합니다.

점수는 **gallery-residual-v1**, 알려진 인코더·원본 후보 모음에서의 연구용 잔여 척도입니다.

높을수록 이 공격에서 되찾기 어렵다는 뜻이며 개인 정보 보호 확률이나 표준·문헌상 신규성·임상 보장이 아닙니다.

실측 0점은 그대로 표시하고 미완료·오류는 숫자로 채우지 않습니다.

같은 강도의 곡선·정확도·점수·그림을 함께 읽고 원비율·정답 수·분모를 확인합니다.
