## 실제 5차 복구·6차 진단·7차 고정 모델

한 번 배우는 것과 흐린 사진에 맞춰 다시 배우는 것은 다른 실험입니다.

6차에서 같은 시험 164장을 읽은 탐색 진단입니다.

| 모델 상태 | 평가 블러 강도 | 정답/시험 영상 |
| --- | --- | --- |
| 기존 모델 고정 | 4 | 82/164장 |
| 블러 4에 맞춰 다시 학습한 기존 모델 | 4 | 164/164장 |

숫자를 비교할 때 먼저 모델이 다시 배웠는지 확인해야 합니다.

7차는 처음부터 블러 없이 한 번만 100회 배운 뒤 모델 하나를 고정하고 열 강도를 평가합니다.

기존 공개 1~5차와 실제 실험 번호는 다른 축입니다.

공개 3차는 학습 2차의 특징 그림 소프트웨어, 공개 4차는 로컬 3차의 선택 화면 수리, 공개 5차는 실제 4차의 고정 100회 코드입니다.

기존 번호·원문은 보존하고 실제 5차 복구를 별도 이름으로 추가했습니다.

실제 3차는 새 학습 실험이 아니라 학습 2차의 화면 수리라는 뜻입니다.

2026-11-20 공개 기록 시점에 7차는 학습 진행 중이며 최종 시험 결과는 미측정입니다.

원영상·영상별 목록·가중치·운영 기록은 공개하지 않습니다.

<a id="guide-intro"></a>

## 프로젝트 소개

CT 사진을 흐리게 하거나 블록으로 재배열했을 때 분류 결과와 영상 유사도가 어떻게 달라지는지 살펴봅니다.

입력 사진을 바꾸는 연구와 모델 내부의 첫 합성곱 특징을 흐리는 실험이 함께 있습니다.

논문 연구 번호·공개 코드 차수·실제 학습 차수는 다릅니다.


<a id="guide-problem"></a>

## 문제와 주요 기능

| 확인 대상 | 설명 |
| --- | --- |
| 분류와 유사도 | 사진의 모양이 바뀌었어도 분류기가 정답을 잘 맞추는지, 얼마나 비슷한 정보를 남기는지 따로 봅니다. |
| OK·NG 라벨 | OK는 양성 + 정상, NG는 악성입니다. |
| 표본 단위 | 사진 수·독립 환자 수·반복 학습 표본 수를 섞지 않습니다. |

<a id="guide-flow"></a>

## 입력·처리·출력

| 확인 대상 | 설명 |
| --- | --- |
| 변환 위치 | 입력 사진에 블러·블록을 적용하는 경로와 모델이 뽑은 특징에 블러를 적용하는 경로를 나눕니다. |
| 특징의 뜻 | 특징은 사진에서 찾은 선·무늬의 반응입니다. |
| 색 해석 | 그 색이 병변 위치나 악성 확률을 뜻하지 않습니다. |

### LEVEL 1 · 입력 변환·분리 모델·특징 블러의 차이

입력 변환은 사진 자체를 바꾸고 특징 블러는 모델이 사진에서 찾아낸 선·무늬의 반응을 바꿉니다.

바꾸는 위치가 다릅니다.

edge와 cloud라는 이름도 두 컴퓨터에서 통신했다는 뜻은 아닙니다.

큰 흐림 조건 여러 개가 같은 결과를 재사용하면 각각 새로 학습한 실험으로 세지 않습니다.

| --- | --- |
| <a id="layout18-table-6-row-1"></a> 입력 변환 | 블러는 PIL GaussianBlur이며 σ0은 복사합니다.<br>블록은 seed 순 열로 위치를 바꾸고 내부 픽셀을 유지하며 영상보다 작지 않은 블록은 복사합니다.<br>조합은 Block10×Blur10 =100이며 Block 뒤 Blur입니다. |

## LEVEL 1·실제 8차·독립 학습과 제안 점수

각 블러 강도에서 새로 100회 배우고, 정답을 얼마나 맞혔는지와 원본을 얼마나 되찾기 어려웠는지를 따로 봅니다. 블러는 모델이 사진에서 추출한 선·무늬의 반응을 흐리는 처리입니다. 7차는 블러 없이 배운 모델 하나를 고정했지만, 8차는 강도마다 새 모델을 배웁니다.

| 차수 | 동작·현재 결과 | 자료 · 상세 · 직전 비교 |
| --- | --- | --- |
| 실제 8차 | 열 강도 각각 100회 → 분류·공격 완료 → 다음 강도. σ0 학습 중·분류 성적과 점수 미측정 | [자료](../../Conv1%20%EB%B8%94%EB%9F%AC%20OK-NG%20%EC%8B%A4%ED%97%98/8%EC%B0%A8) · [상세](../../docs/revisions/conv1-okng-round8.md#user-content-reading-level-1) · [직전 비교](../../docs/revision-diffs/conv1-okng-round8.md) |

화면의 **프라이버시 제안 점수·100점 만점**은 정해진 원본 후보 공격에서 측정한 연구용 점수입니다.

높을수록 그 공격에서 원본을 되찾기 어렵다는 뜻입니다.

공격자가 원본 후보와 특징을 만드는 모델을 이미 알고 있다는 강한 조건을 사용합니다.

정확한 특징 비교로 원본을 모두 찾았다면 점수는 0이고 그대로 보여 줍니다. 100점이라도 개인 정보가 100% 보호된다는 뜻은 아닙니다.

분류 정확도는 정답 여부, 제안 점수는 이 공격에서 남은 복원 오차이므로 서로 다른 질문에 답합니다.

점수는 **gallery-residual-v1**, 알려진 인코더·원본 후보 모음에서의 연구용 잔여 척도입니다.

높을수록 이 공격에서 되찾기 어렵다는 뜻이며 개인 정보 보호 확률이나 표준·문헌상 신규성·임상 보장이 아닙니다.

실측 0점은 그대로 표시하고 미완료·오류는 숫자로 채우지 않습니다.

같은 강도의 곡선·정확도·점수·그림을 함께 읽고 원비율·정답 수·분모를 확인합니다.
