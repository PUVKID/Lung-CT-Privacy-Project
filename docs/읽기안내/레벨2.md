## LEVEL 2·실제 5차 복구·6차 진단·7차 고정 모델

**적응 학습과 고정 모델의 입력 변화는 서로 다른 질문에 답합니다.** 강도별 학습은 남은 특징에 맞춰 분류기가 적응한 결과입니다. 고정 모델 평가는 같은 학습 가중치에서 블러 강도만 바뀐 영향입니다. 6차는 기존 모델을 이용한 진단,7차는 ImageNet 초기값부터 새로 통제한 실험으로 구분합니다.

**기존 공개 1~5차와 실제 실험 번호는 다른 축입니다.** 공개 3차는 학습 2차의 특징 그림 소프트웨어, 공개 4차는 로컬 3차의 선택 화면 수리, 공개 5차는 실제 4차의 고정 100회 코드입니다.

기존 번호·원문은 보존하고 실제 5차 복구를 별도 이름으로 추가했습니다.

실제 3차는 새 학습 실험이 아니라 학습 2차의 화면 수리라는 뜻입니다.

**실제 6차는 기존 5차 모델과 같은 test 164장을 읽은 탐색 진단이고, 실제 7차는 새 ImageNet 초기값으로 시작한 별도 실험입니다.** 2026-11-20 공개 기록 시점에 7차는 학습 진행 중이며 최종 시험 결과는 미측정입니다. 6차 수치를 7차의 빈 결과에 채우지 않습니다.

[6차의 집계 원비율](../../Conv1%20%EB%B8%94%EB%9F%AC%20OK-NG%20%EC%8B%A4%ED%97%98/6%EC%B0%A8/%EA%B2%B0%EA%B3%BC/%EC%A7%91%EA%B3%84_%EC%9B%90%EA%B0%92.json)에서는 분모와 정답 수를 함께 확인합니다.

백분율 요약은 소수 첫째 자리 반올림이며 원비율을 바꾸지 않습니다.

원영상·영상별 목록·가중치·운영 기록은 공개하지 않습니다.

<a id="guide-problem"></a>

## 문제와 주요 기능

이전 연구는 정상·양성·악성 3 분류, Conv1은 OK/NG 이진 분류입니다. 원본 1,097장은 양성 120·정상 416·악성 561장입니다. 클래스당 매 epoch 5,000 표본은 반복·온라인 증강이며 독립 영상 5,000장이 아닙니다.

<a id="guide-flow"></a>

## 입력·처리·출력

연구 1은 512×512 입력에 두 변환을 각각 적용해 정확도·ROC-AUC·혼 동 행렬을 봅니다. 연구 2는 Blur →Block·Block →Blur 조합과 입력 MS-SSIM을 비교합니다. Conv1은 첫 합성곱 특징을 바꾼 뒤 분류합니다.

<a id="guide-practice"></a>

## 실험과 사용 흐름

대표 CT 3 범주와 6 단계에서 조건별 PNG 18개를 만듭니다. 원본 포함 10 조건이 끝나면 180개입니다. 평균·최댓값·개별 8 채널의 총 10 패널은 특징 반응을 보여 줍니다.

<a id="guide-results"></a>

## 관측 결과와 해석

연구 2는 원본 98.17%, Block256 +sigma0 정확도 98.17%·Privacy Score 49.65점을 보고 합니다. 유사도 점수는 복원 공격 성공률이 아닙니다. 연구 1 과 모델·조건이 달라 차이의 원인을 하나로 확정하지 않습니다.

<a id="guide-architecture"></a>

## 구현과 핵심 파일

ResNet50·EfficientNetV2-S 연구와 Conv1 실행 묶음을 구분합니다. dashboard.py는 인증된 결과 조회, 웹 파일은 강도 선택과 사진·곡선 표시를 맡습니다. 원본·가중치·영상별 목록을 응답에 노출하지 않습니다.

<a id="guide-paper"></a>

## 실제 논문과 원고

전체 차수에는 논문·보관 폴더·실험 노트북·Conv1 코드가 있습니다. 폴더 번호를 논문 연구 번호로 읽지 않습니다. 실제 원고·자료·직전 전체 비교에서 당시 조건을 확인합니다.

<a id="guide-limits"></a>

## 조건·실패·미검증 한계

영상 단위 예비실험의 한계, 조건별 학습·결과 재사용, 입력과 특징의 다른 점수 정의를 함께 읽습니다. 새 종료 정책 실험의 준비와 완료도 구분합니다.

### LEVEL 2 · 입력 변환·분리 모델·특징 블러의 차이

원본 사진 →입력 변환 →edge →cloud의 경로와 원본 사진 →edge →특징 블러 →cloud의 경로를 비교합니다. 채널은 서로 다른 특징 반응층이고 depthwise 연산은 각 채널을 따로 흐립니다. decoder는 특징에서 사진을 다시 만드는 별도 모형이므로 분류 점수와 복원 점수를 구분합니다.

### LEVEL 2 · 자료 차수의 수정 도구와 소규모 계산

같은 설정으로 맞추는 비교와 SSIM/PSNR을 맞추는 비교는 목적이 다릅니다. 전자는 학습 조건을 맞추고 후자는 영상 유사도가 비슷한 변환 강도를 찾습니다. 자료 2차는 이 노트북을 생성/수정하며 3차는 작은 입력으로 계산 경로를 점검하고 4차는 원고와 코드를 연결합니다.

## LEVEL 2·실제 8차·독립 학습과 제안 점수

**학습 조건과 공격 조건을 분리해야 숫자의 의미를 읽을 수 있습니다.** 8차는 열 강도에 맞춰 학습하는 실험이며 7차의 고정 모델 평가와 직접 같은 실험이라고 부르지 않습니다.

| 차수 | 동작·현재 결과 | 자료 · 상세 · 직전 비교 |
| --- | --- | --- |
| 실제 8차 | 열 강도 각각 100회 → 분류·공격 완료 → 다음 강도. σ0 학습 중·분류 성적과 점수 미측정 | [자료](../../Conv1%20%EB%B8%94%EB%9F%AC%20OK-NG%20%EC%8B%A4%ED%97%98/8%EC%B0%A8) · [상세](../../docs/revisions/conv1-okng-round8.md#reading-level-2) · [직전 비교](../../docs/revision-diffs/conv1-okng-round8.md) |

첫 합성곱이 고정되어 있으므로 후단 분류기가 강도별로 다르게 학습해도 같은 강도의 전송 특징은 같을 수 있습니다. 분류 정확도가 달라졌다고 공격 점수도 반드시 달라지지는 않습니다. 버전은 **gallery-residual-v1**이며 표준 지표·문헌상 신규성·차등 프라이버시 보장을 검증한 상태가 아닙니다.

점수는 **gallery-residual-v1**, 알려진 인코더·원본 후보 모음에서의 연구용 잔여 척도입니다.

높을수록 이 공격에서 되찾기 어렵다는 뜻이며 개인 정보 보호 확률이나 표준·문헌상 신규성·임상 보장이 아닙니다.

실측 0점은 그대로 표시하고 미완료·오류는 숫자로 채우지 않습니다.

같은 강도의 곡선·정확도·점수·그림을 함께 읽고 원비율·정답 수·분모를 확인합니다.
