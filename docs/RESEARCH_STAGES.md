# 연구 단계와 논문·코드의 연결

## 연구 1 — EfficientNetV2-S 하계 연구

- **학술대회:** 한국컴퓨터교육학회 제58회 2026 하계학술대회.
- **원고:** [EfficientNetV2-S 모델에서 개인정보 보호를 위한 영상 비식별화 기법의 성능 분석](../논문/1차_EfficientNetV2-S_하계_최종.pdf), 3쪽.
- **질문:** 영상의 전역 구조를 흐리는 Blur와 블록 내부 구조를 남기는 재배열 중 어느 변환이 분류에 유리한가?
- **입력·모델:** 512×512 폐암 CT, Benign·Malignant·Normal, EfficientNetV2-S. 원고에 없는 세부 표본 수나 환자별 분할은 연구 2의 값으로 보충하지 않습니다.
- **평가·보고:** 정확도·ROC-AUC·혼동행렬. 원본 92.5%, σ32 53.3%, Block32 79.2%, Block1 52.9%는 원고 보고값입니다.
- **코드 연결:** [하계 그래프](../연구1_하계_EfficientNetV2-S/그래프/Blur_Block_1차_그래프_white.ipynb), [추가 학습 모음](<../추가 학습모델과 실험/Train.ipynb>)의 EfficientNetV2-S 셀. 그래프 입력 JSON과 해당 셀의 학습 설정이 최종 원고 결과를 완전히 재현하는지는 검증하지 않았습니다.
- **한계·다음 단계:** 정확도 감소를 프라이버시 보호율로 대체할 수 없습니다. 원고는 ResNet50 비교 및 엣지 기반 처리로의 확장을 제안합니다.

## 연구 2 — ResNet50 프라이버시·정확도 비교

- **원고 형식:** 한국정보기술학회 논문 양식.
- **원고:** [ResNet50 기반 폐암 CT 분류에서 Block Encryption·Gaussian Blur의 프라이버시-정확도 트레이드오프 분석](../논문/2차_ResNet50_최종.pdf), 19쪽.
- **질문:** 블록과 블러의 단독·조합 변환에서 분류 성능과 MS-SSIM 기반 점수를 함께 높이는 조건은 무엇인가?
- **데이터:** 원고 기준 IQ-OTH/NCCD 1,097장, 3클래스 120·561·416장. 원본에서 클래스별 약 10%를 테스트로 먼저 분리한 구성은 12·56·41장입니다. 이 데이터가 저장소에 포함되지는 않습니다.
- **방법:** ResNet50, 512×512, 블록 512부터 1까지 10조건, σ0부터 256까지 10조건, Block→Blur 100조합. 7-fold·20회 TTA와 고확신도 테스트 의사 라벨 추가 학습을 포함합니다.
- **지표:** 정확도, macro OvR ROC-AUC, 클래스별 Recall. Privacy Score는 원본·변환 영상의 5스케일 MS-SSIM에 대해 `50 × (1 − MS-SSIM)`으로 정의됩니다. PSNR·단일 SSIM은 보조 비교이며 Precision·F1은 논문에서 미산출로 명시합니다.
- **보고 결과:** 원본 98.17%, 조합 Block256+σ0은 98.17%·49.65점·AUC 0.9920. 100조합 중 53개가 51.38%에 도달합니다. Pareto 점 세 개와 단독·조합 실행의 수치 차이는 [README](../README.md)에 정리했습니다.
- **코드 연결:** [블록](<../블록/2차 실험/block_encryption_resnet50_rebuilt_KO.ipynb>), [블러](<../블러/2차 실험/blur_resnet50_rebuilt2_KO.ipynb>), [조합](../블록+블러/block_blur_resnet50_v4_KO.ipynb), [논문용 코드 묶음](<../폐암 2차 논문/코드>).
- **한계:** 테스트 의사 라벨을 사용한 transductive 평가, 증강 파생 영상의 fold 교차 가능성, 환자 그룹 분할의 추가 검증 필요, 조건별 단일 실행, 외부 기관 검증 부재를 함께 고려해야 합니다. MS-SSIM 점수는 실제 복원·재식별 공격이나 사람의 인식 여부를 직접 측정하지 않습니다. 분류 결과표를 다시 그리는 것은 학습 재현이 아닙니다.

## 후속 추가 실험 — edge/cloud 분리와 특징맵 블러

[입력 변환 분리 모델](<../블록+블러 엣지/block_blur_resnet50_edge.ipynb>)과 [Stage 1 특징맵 블러](<../블러 스테이지 1 엣지/stage1_edge_feature_blur_resnet50.ipynb>)를 구분합니다. 전자는 입력 영상에 변환을 적용한 ResNet50을 부분 모델로 나누며, 후자는 `pool1_pool`에서 나온 특징을 변환합니다. 두 부분은 같은 프로세스에서 연결됩니다. 실제 원격 서버 통신·배포·기기 간 전송량 검증은 확인하지 않았습니다.

Stage 1은 σ0·1·2·4·8·16·32·64·128·256을 지정하지만 큰 σ에서는 채널별 전역 평균으로 대체하고 기본값으로 σ32 결과를 더 큰 세 조건에 재사용합니다. 따라서 열 조건의 독립 학습 비교와 다릅니다. 단일 SSIM 특징 점수와 GAP 특징 cosine 유사도를 사용하며, 논문 2의 입력 영상 MS-SSIM 점수와 평가 대상이 다릅니다.

추가 decoder는 동결된 edge 특징으로 원본 영상을 복원하도록 학습하고 PSNR·SSIM을 계산하는 구성입니다. 현재 코드에는 `Conv2D` import/정의가 필요하며, 공격 평가는 논문 2의 후속 과제입니다. 가중치 누락 시 ImageNet 대체, 체크포인트 저장 순서와 예시 데이터 대체 경로도 검토해야 합니다.

## 초기 코드와 그래프 자료의 경계

`원본 실험/Lung Cancer`의 5라벨 Streamlit 화면, 같은 폴더의 3클래스 MobileNetV2 학습, 추가 Train의 조직 영상 5클래스 학습은 별개입니다. 모델 파일 이름·라벨·영상 종류를 함께 확인해야 합니다. 추가 Train에는 EfficientNetV2-S 변환 및 MobileNetV2 풀링 비교도 이어지므로 하나의 연속 파이프라인으로 전체 실행하지 않습니다.

하계 그래프는 결과 JSON을 입력받고, 일부 히트맵은 코드 안의 표를 시각화합니다. 2×2 영상 합성은 기존 영상 파일을 배치합니다. 일부 학습 노트북의 그래프 경로에는 결과·이력·GPU 기록이 없을 때 예시 데이터를 만드는 분기가 있습니다. 도표 출처와 실제 결과 파일을 확인한 뒤 논문 수치와 연결해야 합니다.
