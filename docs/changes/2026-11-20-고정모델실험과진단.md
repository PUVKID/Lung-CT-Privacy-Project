# 실제5차 복구·6차 진단·7차 고정 모델 실험 공개

기존 공개1~5차의 번호와 전체 원문을 유지하고 실제 실험 차수와의 대응을 추가했습니다. **공개5차는 실제4차**이고, 실제5차 복구는 별도 폴더에 보존했습니다. 6차는 기존 모델의 탐색 진단,7차는 새ImageNet초기값에서 시작한 단일σ0모델 실험입니다.

| 추가 범위 | 확인한 내용 | 상태 |
| --- | --- | --- |
| 실제5차 복구 | 과학 조건·결과·checkpoint/RNG 보존과 재개 경계 | 공개 가능한 코드·전체10조건 집계 보존 |
| 실제6차 진단 | 수식·재추론·고정모델·DC·밝기·외곽·최근접·셔플 대조 | 같은test164장 재사용한 탐색 진단 |
| 실제7차 | σ0만100회 → val0최저손실 best1개 →10강도 추가학습0 | 공개 기록 시점 학습 중·최종시험 미측정 |
| 탐색 문서 | 실제1~7차 표·프로젝트5수준·새3차수의5수준 | 기존 설명·코드·원고·PDF 삭제 없음 |

백분율 요약은 소수 첫째 자리 반올림이며 원비율·정답 수·분모·혼동행렬을 집계JSON에서 확인합니다. 6차 비교의 기존σ64 값은 저장 결과이며 이번 기존모델 재추론4조건에는 포함되지 않습니다. 7차의 빈 결과를 기존 관측으로 대신하지 않습니다.

공개 설정 예제의 사적 자료 경로와 manifest SHA는 비워 두었습니다. 실제 실행에는 자신의 원본·분할·고정 기준과 로컬 초기 가중치가 필요합니다. 6차 진단은 자신의 보존 실험 root/run/baseline이 입력이며 자체 config예제는 없습니다. 원영상·특징맵·영상별목록/예측·가중치·접속정보·개인 지침·비공개 운영 기록은 공개하지 않습니다.

| 실제 검사 | 확인 결과 | 범위 |
| --- | --- | --- |
| 공개7차 합성 검사 |36개 중35통과·권한 의존1건 건너뜀, 종료0 | CPU/API/화면상태·단일학습/불변평가·재개 경계 |
| 실제5차 복구 합성 검사 |97개 중96통과·CUDA전용1건 건너뜀, 종료0 | CPU 복구·JSON동시읽기·재개·경로·정합 |

이 검사는 실제7차100회 학습 완료나 환자 독립 성능을 의미하지 않습니다. 새 묶음에 새 논문·원고는 없으며 기존 공개 논문과 PDF는 바이트 그대로 보존합니다. 전체 파일의 추가·수정·삭제와 공백·주석 차이는 [전체 비교](2026-11-20-고정모델실험과진단-전체비교.md)에 연결합니다.
