# 17차 최적 모델 재개 포인터 수정

분류기와 복원 디코더의 last.json 갱신 뒤 best.json 저장 전 중단 시, 재개가 실패하거나 이전 최저 모델을 평가할 수 있었습니다. 첫 완료 회차에서는 current.json도 빠질 수 있었습니다. 중단 창을 CPU 합성자료로 재현해 실패를 확인한 뒤, SHA 검증한 완료 체크포인트의 검증 이력으로 최신 최저 포인터와 마지막 진행 상태를 복구했습니다. 이전 회차가 최저이면 기존 파일의 epoch·SHA·실행 계보·손실을 대조하고 불명확한 경우 거부합니다. 복구는 남은 epoch를 진행하기 전에 수행합니다.

신규 중단/재개6방법과 기존 SCI엔진9·원본공격/셔플6·사진설정1=22방법이 통과했습니다. 독립 검토자는 동일6방법과 동률 첫 최저1방법을 별도로 확인했습니다. 선행29검사·6,469영상 읽기는 변경 없는 부분의 이전 근거를 재사용합니다. 이 수정은 블러·정답·분할·최저손실 선정 원칙을 변경하지 않으며 높은 성능을 인위적으로 낮추지 않습니다. 실제 GPU 전조건·장기 전원 중단·14,000사본 생성·브라우저 실조작은 검증 범위 밖입니다. 12차·원자료·진행 중 프로세스는 수정하지 않았습니다.
