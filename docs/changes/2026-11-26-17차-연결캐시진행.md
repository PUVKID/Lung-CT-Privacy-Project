# 17차 연결 공격·완료 캐시·실제 진행 표시 후속 수정

| 수정 | 동작 | 검증 범위 |
|---|---|---|
| 연결 공격 | 고유 source_id gallery와 원본 단위 정답 판정; canonical 우선 | 같은 원본4사본 합성사례, gallery1/query4 |
| 완료 결과 | run_id 불일치/누락 거부, 조건 결과의 프로토콜·조건도 확인 | 잘못된 실행과 현재 실행 합성 캐시 |
| 공격 진행 | 디코더·복원·연결·멤버십·셔플 실제 처리 수를 API와 화면에 표시 | CPU 상태 갱신, HTTP와 화면 함수 |

분류 정확도·블러 강도·분할·표본수는 유지했습니다. 신규 CPU4·API/화면1과 영향 CPU8·기존 UI2가 통과했습니다. 실제17차 전체 학습·복원 성능·브라우저 조작 검증은 별도입니다. 증강 query는 독립 환자가 아니며 gallery 수와 query 수를 구분합니다. 소스/설명 변경이며 새 릴리스·Docker 변경은 없습니다.
