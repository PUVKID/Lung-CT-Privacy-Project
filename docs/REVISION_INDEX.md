<a id="layout18-table-1-row-1-field-1"></a>

**[연구 1 · 하계 EfficientNetV2-S](revisions/study-1.md)**

**주요 내용**

EfficientNetV2-S에서 입력 CT 영상에 Gaussian Blur와 블록 재배열을 각각 적용했을 때 분류 결과가 어떻게 달라지는지 비교한 하계 3쪽 연구입니다.

<a id="layout18-table-1-row-2-field-1"></a>

**[연구 2 · ResNet50 후속 원고](revisions/study-2.md)**

**주요 내용**

ResNet50에서 Block·Blur 단독 20조건과 Block→Blur 조합 100조건을 비교하고, 분류 정확도와 영상 유사도 기반 점수를 함께 읽는 19쪽 후속 원고입니다.

<a id="layout18-table-1-row-3-field-1"></a>

**[1차](revisions/folder-1.md)**

**주요 내용**

블록·블러의 rebuilt·same_settings·metric_matched 변형과 노트북 수정 보조 스크립트를 함께 읽는 코드 자료 차수입니다.

<a id="layout18-table-1-row-4-field-1"></a>

**[폴더 2차](revisions/folder-2.md)**

**주요 내용**

기존 Blur·Block 노트북의 학습·모니터 출력을 맞추고 Block→Blur 조합 노트북을 만드는 JavaScript 보조 도구 단계입니다.

<a id="layout18-table-1-row-5-field-1"></a>

**[폴더 3차](revisions/folder-3.md)**

**주요 내용**

SSIM에서 DSSIM 기반 Privacy Score를 계산하는 경로와 3장·8조건의 저장 결과를 확인하는 자료 차수입니다. 전체 논문의 1,097장 실험과 구분합니다.

<a id="layout18-table-1-row-6-field-1"></a>

**[폴더 4차](revisions/folder-4.md)**

**주요 내용**

ResNet50 후속 원고와 입력 변환·유사도·도표 코드를 연결해 읽는 자료 차수입니다. 실제 코드 폴더는 자료차수/4차/코드에 있습니다.

<a id="layout18-table-1-row-7-field-1"></a>

**[블러 · 2차 실험](revisions/experiment-6.md)**

**주요 내용**

입력 영상에 PIL GaussianBlur를 적용하는 10조건 실험입니다. σ0은 원본 배열을 복사합니다.

<a id="layout18-table-1-row-8-field-1"></a>

**[블록 · 2차 실험](revisions/experiment-7.md)**

**주요 내용**

시드로 정한 순열에 따라 입력 블록의 위치를 바꾸며 블록 내부 픽셀 배열은 유지합니다. 영상보다 작지 않은 블록은 원본을 복사합니다.

<a id="layout18-table-1-row-9-field-1"></a>

**[블록+블러 · 기본](revisions/experiment-8.md)**

**주요 내용**

블록 10개와 블러 10개의 100조합을 비교합니다. 입력 영상을 블록 재배열한 뒤 Gaussian Blur를 적용합니다.

<a id="layout18-table-1-row-10-field-1"></a>

**[블러 엣지 · 기본](revisions/experiment-9.md)**

**주요 내용**

입력 영상을 블러 처리한 뒤 ResNet50의 pool1_pool 경계에서 edge와 cloud로 나눈 모델을 연결합니다.

<a id="layout18-table-1-row-11-field-1"></a>

**[블록 엣지 · 기본](revisions/experiment-10.md)**

**주요 내용**

입력 블록을 재배열한 뒤 pool1_pool 경계에서 edge와 cloud로 나눈 모델을 학습합니다.

<a id="layout18-table-1-row-12-field-1"></a>

**[블록+블러 엣지 · 기본](revisions/experiment-11.md)**

**주요 내용**

입력 Block→Blur의 100조합 뒤에 분리 모델을 연결합니다. 경계 특징에 FeatureGaussianBlur를 넣는 Stage1 실험과 변환 위치가 다릅니다.

<a id="layout18-table-1-row-13-field-1"></a>

**[블러 스테이지 1 엣지 · 기본](revisions/experiment-12.md)**

**주요 내용**

<a id="layout18-table-1-row-14-field-1"></a>

**[원본 실험 · 기본](revisions/experiment-13.md)**

<a id="layout18-table-1-row-15-field-1"></a>

**[추가 학습모델과 실험 · 기본](revisions/experiment-14.md)**
