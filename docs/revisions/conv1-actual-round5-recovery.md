## LEVEL 1 - Beginner

**실제 5차는 끊긴 학습을 이어 가는 복구 차수입니다.** 기존 공개 폴더 `5차`는 실제 4차의 코드였으므로, 이 복구 자료는 `실제5차_학습복구`에 따로 둡니다.

| 단계 | 무엇을 확인하나요? | 결과 |
| --- | --- | --- |
| 보존 | 원본·분할·설정·체크포인트와 결과를 먼저 고정 | 기존 결과를 새 성능으로 만들지 않음 |
| 변환 | 자료 위치와 실행 ID, 연결 SHA만 명시적으로 변환 | 학습 tensor·optimizer·scheduler·RNG 유지 |
| 재개 | 마지막 완료 회차 다음 회차의 처음부터 | 미완료 배치의 중간 진행을 정확히 복원한다고 주장하지 않음 |
| 관찰용 종료 | 종료 전에는 prefix 파일이 없는 상태도 허용 | 종료·SHA·파일 존재가 모순되면 거부 |

모델 파일에는 배운 숫자뿐 아니라 다음 학습을 이어 갈 상태가 들어 있습니다.

옮긴 파일이 같은지 해시로 확인한 뒤 완료한 강도는 건너뛰고 남은 회차를 이어 갑니다.

가짜 결과나 없는 prefix를 만들어 채우지 않습니다.

당시 재개 지점과 현재 전체 완료 여부는 다릅니다.

이 공개 사본에는 실제 복구 파일이나 경로 목록이 없습니다.

환자 ID가 없어 **영상 단위 예비실험**입니다. 같은 환자의 다른 영상이 분할 양쪽에 남았는지 확인할 수 없고 임상 일반화·환자 독립성·프라이버시 달성을 주장하지 않습니다. 클래스당 5,000개는 매 회차 반복·온라인 증강 표본이며 독립 원본 5,000장이 아닙니다.

## LEVEL 2 - Explorer

**복구는 새 실험 설계가 아니라 저장 위치·실행 계보를 함께 옮기는 과정입니다.** 강도별로 따로 학습하는 기존 프로토콜을 유지합니다.

| 조건 | 실제 설정 | 해석 |
| --- | --- | --- |
| 자료 | 원본 1,097장, train769/validation164/test164 | 원본을 분할한 뒤 학습에만 온라인 증강 |
| 분류 | OK =양성 + 정상, NG =악성 | 원본 폴더 라벨이며 환자·기관 ID가 아님 |
| 모델 | torchvision ResNet50 V1.5, conv1·모든 BN 고정 | layer4 비BN와 head 학습 |
| 표본·정밀도 | 클래스당 5,000, batch8, 512×512, BF16 학습·FP32 평가 | 평가 손실은 FP64 안정 계산 |
| 선택 | 검증 손실 기준 | 시험 수치로 모델·σ·임계값 선택 없음 |

자료 내용·라벨·분할과 과학 조건은 유지하고 위치가 바뀐 경로 및 파생 식별자를 새 실행으로 연결합니다.

최초 가져 오기 검사는 당시 파일 SHA를 고정하고, 재개 후 달라지는 last/history는 진행 검증으로 구분합니다.

관찰용 종료 전에는 stop/best0·SHA 없음·prefix 없음이 함께 정상이어야하고, 종료 뒤에는 실제 prefix와 연결 SHA를 확인합니다.

환자 ID가 없어 **영상 단위 예비실험**입니다. 같은 환자의 다른 영상이 분할 양쪽에 남았는지 확인할 수 없고 임상 일반화·환자 독립성·프라이버시 달성을 주장하지 않습니다. 클래스당 5,000개는 매 회차 반복·온라인 증강 표본이며 독립 원본 5,000장이 아닙니다.

`config.example.json`을 자신의 `config.json`으로 만들고 자료 경로와 기준 manifest 파일·records SHA를 채웁니다.

복구 도구는 외부에서 고정·검토한 baseline SHA를 요구합니다.

현재 파일 해시로 baseline을 바꾸면 과거 보존 검증이 아니므로 그렇게 하지 않습니다. `복구_학습.py --device cuda --baseline-sha256 <자신의 고정값>`은 자료·환경·복구 기준을 직접 준비한 경우에만 실행합니다.
