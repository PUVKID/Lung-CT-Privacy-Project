### LEVEL 1 · Conv1 실험의 분할·수치·공개 차수

사진에서 선과 무늬를 찾아 흐리게 한 뒤 OK·NG 두 범주로 나누는 첫 실험입니다. 같은 원본을 변형해 여러 번 보는 학습과 서로 다른 원본 수를 구분합니다.

| 조건·자료 | 이 차수의 내용 |
| --- | --- |
| <a id="layout18-table-1-row-1"></a> **분류와 표본** | **OK = 양성 + 정상, NG = 악성**입니다.<br>원본 분할 후 학습에만 온라인 증강을 적용하여 클래스당 매 epoch 5,000개를 구성합니다. 서로 다른 원본 사진 5,000장을 뜻하지 않습니다. |
| <a id="layout18-table-1-row-2"></a> **차수 범위** | **Conv1 블러 OK/NG의 첫 차수**입니다.<br>직전 동일 실험 차수는 없으며 상위 프로젝트의 이전 자료와 원고는 별도로 보존합니다. |
| <a id="layout18-table-1-row-3"></a> **구현과 한계** | 고정 첫 합성곱 특징에 블러를 적용하고 Cloud 분류기를 학습합니다.<br>Windows CUDA의 torchvision ResNet50 V1.5 구현이며 첨부 TensorFlow 노트북과 가중치·전처리·stride가 다릅니다. 환자 ID가 없어 영상 중복 그룹 단위 예비실험입니다. |
| <a id="layout18-table-1-row-4"></a> **당시 구현 검사** | **단위/통합 검사 33개**와 실제 reader/writer 동시 500회 교체를 확인했습니다.<br>BF16 512픽셀 사전 학습 모델의 연속 배치·검증 연결 기록이며 전체 10조건 학습 완료나 환자 단위 성능 검증은 아닙니다. |
| <a id="layout18-table-1-row-5"></a> **공개와 연결** | 학습·분할·증강·블러 코드, 검사, 로컬 대시보드와 글꼴·라이선스를 공개합니다.<br>의료 영상·영상별 목록·가중치·로그·개인 지침·접속 정보는 제외합니다. 전체 차수와 공통 안내는 [프로젝트 첫 화면](../../README.md)에서 확인합니다. |

**양성·정상을 OK, 악성을 NG로 묶어 고정 첫 합성곱 특징에 블러를 적용한 뒤 Cloud 분류기를 학습합니다.** 학습 표본은 원본 분할 이후에만 온라인 증강으로 클래스당 매 epoch 5,000개를 구성합니다.

환자 식별자가 없어 영상 중복 그룹 단위 예비실험이며 환자 독립성이 검증되지 않았습니다.

가중치·전 처리·stride가 달라 원본 수치 재현이 아닙니다. 7-fold CV, 고정 모델 평가, 원본 영상 매칭 및 복원 공격은 이번 실행 범위에 포함되지 않습니다.

학습 완료나 성능 수치를 사전에 주장하지 않습니다.

이 실험 묶음의 첫 차수이므로 직전 동일 실험 차수는 없습니다. 상위 프로젝트의 1~4차 및 이전 특징 블러 실험은 보존합니다. 기존 원고는 변경하지 않았고 이번 묶음에 새 논문 원고는 없습니다.
