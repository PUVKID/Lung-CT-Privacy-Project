### LEVEL 1 · Conv1 실험의 분할·수치·공개 차수

같은 학습을 100회까지 이어 가면서 이전 정책이라면 언제 멈췄을지 함께 기록하는 비교를 준비했습니다. 준비와 실제 학습 완료는 다릅니다.

| 조건·자료 | 이 차수의 내용 |
| --- | --- |
| <a id="layout18-table-1-row-1"></a> **분류와 비교 범위** | **실제 실험 4차를 공개 5차로 보존**합니다.<br>원본 환자 ID가 없어 영상 단위 예비실험이며 학습 온라인 표본과 독립 원본 수를 구분합니다. |
| <a id="layout18-table-1-row-2"></a> **직전 공개 4차 대비** | 학습을 강도마다 100회까지 진행하고 실제 조기 종료는 끈 채 기존 종료 정책을 관찰합니다.<br>화면의 기존 강도 선택은 유지합니다. 직전 기능은 [공개 4차 설명](conv1-okng-round4.md)에서 확인합니다. |
| <a id="layout18-table-1-row-3"></a> **고정한 조건** | 원본 목록·정확한 분할·모델·초기 seed·학습 전용 증강·클래스당 5000개·배치·AdamW·검증 손실 기반 학습률 감소를 유지합니다.<br>기준 manifest·원본 목록 해시가 실제 입력과 다르면 중단합니다. |
| <a id="layout18-table-1-row-4"></a> **검증과 관측 범위** | CPU 단위·통합 검사와 실제 GPU 배치 연결은 실행·제어 동작의 검사입니다.<br>최종 직접 검사 수는 별도 검증 기록에서 확인하며 새 실험의 최종 성능이나 전체 10조건 학습 완료를 사전에 보고하지 않습니다. |
| <a id="layout18-table-1-row-5"></a> **공개와 공통 안내** | `source_class`는 원본 범주 폴더 라벨이며 병원·환자·스캐너 ID가 아닙니다.<br>의료 영상·특징맵 PNG·원본 목록·가중치·운영 기록·접속 정보·개인 계획서는 제외합니다. 전체 흐름은 [프로젝트 첫 화면](../../README.md)에서 확인합니다. |

### LEVEL 1·고정 100회와 관찰용 조기 종료 비교

학습을 100회까지 계속하면서 예전 규칙이라면 언제 멈췄을지 따로 적습니다. **관찰용 종료는 실제 학습을 멈추지 않습니다.** 앞부분에서 골랐을 모델과 100회 전체에서 고른 모델을 같은 시험으로 비교해 종료 정책을 살핍니다. 아직 없는 최종 성능을 만들어 쓰지 않습니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-2-row-1"></a> 차수와 정책 | 실제 실험 4차를 공개 5차로 보존합니다.<br>원본/분할·모델·seed·학습 증강·클래스당 5000·batch·AdamW·val_loss 학습률 감소는 유지하고 10 강도 각 100회까지 학습하며 실제 조기 종료는 끄고 관찰만 합니다. |
| <a id="layout18-table-2-row-2"></a> 선택과 재개 | 기존 정책이 멈췄을 첫 회차와 그때까지 최저 검증 모델, 전체 100회 최저 검증 모델을 같은 시험 자료로 비교합니다.<br>같은 학습 경로의 앞부분/전체에서 고른 모델이며 관찰 상태·가중치·optimizer·scheduler·RNG를 재개 시 보존합니다. |
| <a id="layout18-table-2-row-3"></a> 필수 입력 | expected_reference_manifest·expected_reference_manifest_sha256·expected_reference_records_sha256를 자신의 기준 manifest로 채워야 합니다.<br>예제에는 실제 식별 해시가 없어 그대로 실행할 수 없으며 원본 목록/정확한 분할이 불일치하면 중단합니다. |
| <a id="layout18-table-2-row-4"></a> 표시와 한계 | 기본 백분율은 첫째 자리 반올림이며 원비율·전체 백분율·정답 수를 펼쳐 100.0% 반올림과 전부 정답을 구분합니다.<br>결과 API는 혼동 행렬/정답 수/정확도 일관성도 대조합니다.<br>시험셋 재사용의 탐색 비교이며 새 독립 임상 검증·전 조건 학습 완료를 주장하지 않습니다. |

## 비교 조건

 같은 원본과 분할 →  같은 모델·초기값·학습 표본 →  강도마다 100회 학습 →  종료 정책에 따른 두 모델 비교 순서입니다.

| 유지하는 조건 | 바꾸거나 추가한 조건 |
| --- | --- |
| 원본 목록·정확한 학습/검증/시험 분할 | 기준 manifest 파일·원본 목록 해시 및 실제 분할 동일성 검사 |
| 모델·초기 seed·학습 전용 증강·클래스당 5000개 온라인 표본 | 조기 종료를 비활성화하고 강도마다 100회 학습 |
| 배치·AdamW·검증 손실 기반 학습률 감소 | 기존 정책이 멈췄을 첫 회차와 그때까지의 검증 최저 모델을 관찰용으로 별도 보존 |

이미 사용한 분할과 시험셋을 다시 이용하므로 탐색적 종료 정책 비교이며 새 독립 임상 검증이 아닙니다.

## 수치와 화면

백분율 요약은 소수 첫째 자리까지 반올림합니다. 원비율·전체 백분율·정답 수를 함께 확인할 수 있어 반올림된 100.0%와 실제 모든 정답을 구분합니다. AUC·손실·학습률의 원값 조회는 유지하며 원본 결과 파일의 수치를 바꾸지 않습니다.

새 실행 기록이 아직 없으면 대기 상태를 표시하고 결과 요청을 보내지 않습니다. 인증된 결과 API는 수치 타입·유한성·범위뿐 아니라 혼동 행렬과 정답 수·정확도의 일관성을 대조합니다. 다른 실행이나 모순된 값은 결과로 표시하지 않습니다. 이 검사는 모든 미래 결함을 방지한다는 보장이 아닙니다.

## 실행에 필요한 자체 자료

공개 설정 예제에는 개인 데이터 경로와 기준 manifest의 실제 식별 해시를 넣지 않습니다.

사용자는 자신의 원본과 기준 manifest를 준비하고 `expected_reference_manifest`, `expected_reference_manifest_sha256`, `expected_reference_records_sha256`를 채워야 합니다.

예제 그대로는 기준 비교를 실행할 수 없습니다.

원본 목록과 정확한 분할이 다르면 중단하는 검증 코드는 유지합니다. [공개 실행 방법](../../Conv1%20블러%20OK-NG%20실험/5차/docs/실행방법.md)을 따릅니다.

특징맵 저장 도구는 [이전 공개 4차의 도구](../../Conv1%20블러%20OK-NG%20실험/4차/생성%20도구/사용방법.md)를 재사용할 수 있습니다. `--experiment-root`, `--output-root`, `--reference-root`, `--run-id`를 새 실험의 실제 값으로 명시합니다.

새 실험의 특징맵 사진을 이미 생성했다는 뜻은 아닙니다.
