## LEVEL 1 - Beginner

<a id="semantic-lung-view-level-1"></a>

| 항목 | 이 차수의 내용 |
| --- | --- |
| 목적 | 블러 강도를 바꿔도 사진만 바뀌고 학습 곡선·시험 수치는 마지막 강도에 남던 문제를 수정했습니다.<br>이제 강도 하나를 고르면  사진· 학습 곡선· 시험 결과가 함께 바뀝니다. 상단의 마지막 실행 상태와 사용자가 고른 결과를 구분해 표시합니다. |
| 변경 | 학습 2차 대시보드의 로컬 수리 3차를 공개 코드 4차로 보존했습니다.<br>새 학습 차수 3·4를 시작한 것이 아닙니다. |
| 조건 | 등록된 강도는 0·1·2·4·8·16·32·64·128·256입니다.<br>결과를 살펴보는 선택 기능이며 시험 수치를 이용해 학습 조건을 정하는 기능은 아닙니다.<br>실제 학습 코드·설정·분할·기록·결과·체크포인트는 수정하지 않습니다. |
| 동작 | `dashboard.py`: 인증된 읽기 전용 `/api/sigma-results/<강도>`에서 현재 실행과 일치하는 숫자만 제공합니다.<br>등록된 강도·경로 경계·파일 크기·결과 식별자와 수치의 타입·유한성·범위를 검사합니다.<br>정확도·AUC는 0~1, 손실·학습률은 음 수가 아닌 유한 수, 회차·갱신 횟수·영상 수는 불리언과 구분한 정수로 확인합니다.<br>원본 경로·개별 예측·가중치를 반환하지 않습니다. |
| 결과 | 정확도 요약은 백분율 소수 둘째 자리까지 표시하고 이후 자리는 버립니다.<br>예를 들어 저장 비율이 0.98789이면 요약은 98.78%이며 98.79%로 올리지 않습니다.<br>이 값은 표시 방법을 설명하는 예시로 실제 실험 성능이 아닙니다. |

### LEVEL 1 · 단계별 특징맵과 강도 선택 화면

강도를 고르면 사진뿐 아니라 학습 곡선과 시험 수치도 함께 바뀌도록 고쳤습니다. 아직 결과가 없으면 마지막 결과를 대신 보여 주지 않습니다.

| 조건·자료 | 이 차수의 내용 |
| --- | --- |
| <a id="layout18-table-1-row-1"></a> **차수 범위** | 학습 2차용 로컬 화면 수정 3차를 공개 4차로 보존했습니다.<br>새 학습 실험을 시작한 변경이 아니며 단계별 사진 구성은 [직전 공개 3차 설명](conv1-okng-round3.md#user-content-reading-level-1)에서 확인합니다. |
| <a id="layout18-table-1-row-2"></a> **유지한 자료** | 학습 소스·설정 예제·의존성·특징맵 생성 도구를 유지합니다.<br>실제 학습 폴더와 결과·체크포인트를 공개 사본으로 교체하지 않습니다. |
| <a id="layout18-table-1-row-3"></a> **결과 경계** | 읽기 전용 인증 API `/api/sigma-results/<강도>`는 등록 강도·경로·파일 크기·실행 식별자와 수치의 타입·유한성·범위를 검사합니다.<br>원본 경로·개별 예측·가중치를 반환하지 않습니다. |
| <a id="layout18-table-1-row-4"></a> **선택과 응답 순서** | 사진·학습 곡선·시험 수치가 같은 강도로 바뀝니다.<br>3초 갱신·테마·화면 크기 변경에도 선택을 유지하며 빠른 0 → 256 → 0 선택의 늦은 응답을 버립니다. 실행 전환 시 이전 수치를 비웁니다. |
| <a id="layout18-table-1-row-5"></a> **이 차수의 수치 표시** | 백분율은 소수 둘째 자리까지 버림 표시하고 원비율·전체 자릿수를 함께 제공합니다.<br>미완료·누락·다른 실행·잘못된 결과는 대기 또는 미측정으로 표시합니다. 이 기록은 해당 차수 당시의 표시 방식입니다. |
| <a id="layout18-table-1-row-6"></a> **당시 검사와 한계** | **전체 명세 52개(대시보드 25개)**, Node 문법·지연 응답 회귀·실제 10강도 응답 원값 대조 기록입니다.<br>초기 모의 DOM 누락 등 2건의 실패와 후속 중첩 객체 결함·수리를 보존합니다. 임상 성능이나 전체 무오류 보장이 아닙니다. |
