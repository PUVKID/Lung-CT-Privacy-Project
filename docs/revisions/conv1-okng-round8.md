## LEVEL 1 - Beginner

**각 블러 강도에서 새로 100회 배우고, 정답을 얼마나 맞혔는지와 원본을 얼마나 되찾기 어려웠는지를 따로 봅니다.** 블러는 모델이 사진에서 추출한 선·무늬의 반응을 흐리는 처리입니다. 7차는 블러 없이 배운 모델 하나를 고정했지만, 8차는 강도마다 새 모델을 배웁니다.

| 단계 | 하는 일 | 화면에서 확인 |
| --- | --- | --- |
| 학습 | 같은 초기 가중치에서 해당 강도만 100회 학습 | 선택 강도의 회차·손실 곡선 |
| 모델 선택 | 가중치 학습에 쓰지 않은 검증 영상의 손실이 가장 낮은 모델 선택 | 선택 회차와 모델 식별값 |
| 분류 평가 | 학습에 쓰지 않은 시험 영상의 OK·NG를 예측 | 정답 수/전체 수와 정확도 |
| 원본 후보 공격 | 알고 있는 원본 후보들을 같은 방법으로 특징으로 바꿔 비교 | 프라이버시 제안 점수와 원값 |

먼저 강도 0의 100회 학습을 끝내고 그 모델의 분류와 공격 점수를 실제 계산합니다. 그 다음 강도 1에서 처음부터 같은 순서를 반복합니다. 강도 8 버튼을 누르면 강도 8의 곡선·정확도·점수·그림으로 바뀝니다. 아직 배우거나 계산하지 않은 강도에는 미측정·대기라고 표시하며 다른 강도의 결과를 대신 넣지 않습니다.

화면의 **프라이버시 제안 점수·100점 만점**은 정해진 원본 후보 공격에서 측정한 연구용 점수입니다.

높을수록 그 공격에서 원본을 되찾기 어렵다는 뜻입니다.

공격자가 원본 후보와 특징을 만드는 모델을 이미 알고 있다는 강한 조건을 사용합니다.

정확한 특징 비교로 원본을 모두 찾았다면 점수는 0이고 그대로 보여 줍니다. 100점이라도 개인 정보가 100% 보호된다는 뜻은 아닙니다.

분류 정확도는 정답 여부, 제안 점수는 이 공격에서 남은 복원 오차이므로 서로 다른 질문에 답합니다.

환자 ID가 없어 **영상 단위 예비실험**입니다.

같은 환자의 서로 다른 영상이 분할 양쪽에 있는지는 확인할 수 없습니다.

독립 환자 성능·임상 진단·환자 재식별 방어로 확대하지 않습니다.

클래스당 5,000개는 매 회차 반복·온라인 증강한 학습 표본 수이며 독립 원본 5,000장이 아닙니다.

원영상·영상별 목록·예측·그룹별 공격 원 자료·특징 그림·가중치·접속 정보는 공개하지 않습니다.

**2026-11-20 확인 시점에 8차는 σ0 학습 중이며 실제 분류 정확도와 제안 점수는 미측정입니다.** 합성 검사에서 사용한 0점·100점·정확도는 검사 입력이며 CT 실험 결과가 아닙니다. 5·6차 수치를 새 8차의 결과에 채우지 않습니다.

## LEVEL 2 - Explorer

**학습 조건과 공격 조건을 분리해야 숫자의 의미를 읽을 수 있습니다.** 8차는 열 강도에 맞춰 학습하는 실험이며 7차의 고정 모델 평가와 직접 같은 실험이라고 부르지 않습니다.

| 구성 | 조건 | 연결되는 결과 |
| --- | --- | --- |
| 입력 분할 | 원본 1,097장·학습 769/검증 164/시험 164 | 분류의 시험 분모와 학습 자료 분리 |
| 분류 모델 | conv1 과 모든 BN 고정·layer4 비BN/head 학습 | 강도별 100회 후 최저 검증 손실 모델 |
| 공격 입력 | 알려진 인코더·원본 후보·FP32·패킷 1장 | 동일 픽셀 원본을 합친 G개 후보 그룹 |
| 공격 결과 | 실제 특징 바이트가 같은 후보를 동점으로 취급 | 후보별 잔여를 먼저 계산한 뒤 평균 |

OK는 양성 + 정상, NG는 악성입니다.

모델은 각 강도에서 같은 로컬 ImageNet 초기 가중치로 시작하지만 optimizer·scheduler·난수 상태를 다시 만듭니다. 100회가 끝난 뒤 손실이 가장 작았던 회차를 선택하므로 선택 모델이 반드시 100번째 모델이라는 뜻은 아닙니다.

시험 결과로 모델·강도·임계값을 고르지 않습니다.

공격의 원본 후보 모음을 gallery라고 합니다.

전처리 후 픽셀이 같은 영상은 한 그룹으로 합치며 이 그룹은 환자 그룹이 아닙니다.

정답 후보를 공격자에게 알려서 고르지 않고, 실제 특징이 같은 후보 전체에 균등 선택을 적용합니다.

원본을 정확히 반환하면 잔여는 0, 상수 특징으로 모든 후보가 동점이면 균등 후보 기준과 같아 100점이 됩니다.

이는 두 대조 군의 정의이며 실제 CT 모델의 측정 값을 미리 결정하지 않습니다.

첫 합성곱이 고정되어 있으므로 후단 분류기가 강도별로 다르게 학습해도 같은 강도의 전송 특징은 같을 수 있습니다. 분류 정확도가 달라졌다고 공격 점수도 반드시 달라지지는 않습니다. 버전은 **gallery-residual-v1**이며 표준 지표·문헌상 신규성·차등 프라이버시 보장을 검증한 상태가 아닙니다.

## LEVEL 3 - Practitioner

**공개 코드는 자신의 비공개 입력과 고정 기준을 준비해야 실행할 수 있습니다.** 설정 예제는 원본 영상·분할 manifest·가중치·실제 운영 경로를 포함하지 않습니다.

| 순서 | 준비·실행 | 확인할 산출물 |
| --- | --- | --- |
| 입력 준비 | config.example.json을 config.json으로 복사하고 자신의 자료 경로·SHA 입력 | 원본/분할/초기 가중치 불변 기준 |
| 합성 검사 | 별도 공개 사 본에서 tests의 단위 검사 실행 | 합성 점수 대조 군·API·상태 경계 |
| 실험 준비 | run_training.py prepare | 현재 소스와 입력에 결합된 run metadata |
| 학습 감독 | 안전 _학습.py에 검토한 baseline SHA 전달 | σ별 100회 이력·선정·분류·점수 |
| 결과 읽기 | 자신의 로컬 dashboard.py 실행 | 선택 강도의 수치·원값·완료 그림 |

전체 단위 검사 중 실제 ResNet50 경로 검사에는 로컬 ImageNet V1초기 가중치가 필요합니다.

공개 예제를 임시 설정으로 준비한 뒤 initial_weights_path를 자신의 SHA 검증된 파일에 연결해야하며 가중치를 공개하지 않습니다.

실제 실행 전 데이터셋 경로, 기준 manifest의 파일 SHA와 records SHA, 로컬 ImageNet V1 가중치와 SHA를 채워야 합니다.

예제의 빈 기준으로 실제 학습을 시작할 수 없습니다.

원본 분할을 먼저 고정하고 온라인 증강은 학습에만 적용합니다.

진행 중인 학습이 있거나 이미 학습 이력이 생긴 작업에서는 prepare·smoke가 상태를 덮어쓰지 않도록 거부합니다.

분류 평가가 끝나고 점수가 아직 계산 중이면 정확 도는 읽을 수 있지만 점수는 미측정입니다. 점수 오류가 생겨도 0점으로 대체하지 않습니다. 양쪽 평가가 모두 끝나야 그 강도가 완료되고 다음 강도 학습으로 넘어갑니다. 결과의 실행·소스·입력·선정 모델 결합이 다르면 API는 해당 결과를 거부합니다.

## LEVEL 4 - Advanced

**학습·분류·공격·조회가 각 강도의 선정 모델과 입력을 함께 검증합니다.** 파일이 존재한다는 사실만으로 완료 결과를 제공하지 않습니다.

| 모듈 | 책임 | 실패 경계 |
| --- | --- | --- |
| src.training | 강도 마다 상태 재설정·100회 학습·모델 선정·후속 평가 | privacy 완료 전 다음 강도로 진행하지 않음 |
| src.privacy | 그룹화·별도 gallery/query forward·정확 특징 사전 공격 | 비유한값·미확인 매칭·부적절한 분모 거부 |
| src.identity | source/manifest/selection/checkpoint·raw 재집계 | 잘못된 실행·모델·원값 변조 거부 |
| dashboard.py | 읽기 전용 whitelist·원값/단계 제공 | Host·인증·경로·모델 연결 검증 |
| feature_generator | 완료 강도마다 CPU로 18장 생성 | schema3의 각 item에 해당 강도 모델 결합 |

selection은 강도마다 별도 checkpoint SHA와 모델 전체 state SHA를 가집니다.

분류와 공격은 추가 optimizer 갱신 0에서 수행하고 모델의 eval 상태와 상태 불변을 확인합니다.

학습 BF16/분류 FP32 batch8과 공격 FP32 packet batch1은 서로 다른 계산 조건입니다.

점수는 batch8 분류 패킷을 그대로 공격한 증거가 아닙니다.

API는 원영상별 예측이나 그룹별 원자료 경로를 반환하지 않습니다.

점수 원자료의 거리·후보·그룹·파이프 라인을 서버 내부에서 재계산하고 현재 소스·입력·선정 파일과 대조한 안전한 집계만 내보냅니다.

특징 index는 공통 체크포인트 하나를 갖지 않고 각 강도의 identity를 담습니다.

전체 목록은 완료 묶음 전체를 검증하며 이미지 한 장 요청도 공통 경계와 그 강도의 18장 묶음·PNG 바이트 SHA를 검증합니다.

## LEVEL 5 - Expert

**프로토콜 independent-sigma-privacy-v1은 열 강도의 독립 100회 학습과 gallery-residual-v1 공격을 결합합니다.** σ={0,1,2,4,8,16,32,64,128,256}; 각 조건의 raw validation loss 최저 모델을 선택하며 조기 종료는 비활성입니다.

공격 후보 S_i에 T_attack =Σ_i [Σ_(j ∈S_i)t_ij/|S_i |]/G, 균등 후보 기준 T_prior =Σ_i Σ_j t_ij/G², P =100·clip(T_attack/T_prior,0,1)입니다.

후보별 clip을 평균보다 먼저 수행하며 clip(E[d]/b)로 바꾸지 않습니다.
