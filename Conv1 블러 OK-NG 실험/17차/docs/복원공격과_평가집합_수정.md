# 복원 공격·라벨 셔플·평가 집합 연결

17차의 원본 자료, 환자 분할, 클래스별 고정 학습5,000·검증1,000·시험1,000개 계약은 유지합니다. 저장 공간 이전은 별도 작업이며 이 수정으로 경로·파일·학습 프로세스를 옮기지 않습니다.

## 복원 공격

기존 특징 역복원은 전달 특징과 일치하는 **블러 후 사진**을 추정하는 공격으로 보존합니다. 별도로 **블러 전 원본 후보 → 알려진 Gaussian 블러 → 특징 추출 → 전송 정밀도 변환** 경로를 거쳐 전달 특징과 맞추는 원본 공간 공격을 추가합니다.

원본 공간 공격은 학습 평균영상과 일정 밝기 등 사전에 고정한 초기값에서 시작합니다. 같은 전달 특징과 TV 사전 목적만으로 초기값별 후보를 선택하며 시험 정답 사진의 MSE로 초기값을 고르지 않습니다. 공격군을 고르는 정책 역시 검증 집합 전용입니다. 시험 원본은 최종 복원 오차를 측정할 때만 사용합니다.

FP16·INT8은 실제 전송 값과 같은 전방 정밀도 변환을 사용하되, 최적화의 역전파는 STE 근사입니다. 양자화의 엄밀한 미분이나 최강 공격임을 주장하지 않습니다. 고정 반복 횟수와 초기값은 공개 설정·결과에 기록하고, 공격을 추가했다는 사실과 실제 보호 점수가 달라졌는지를 구분합니다. 원래 사진/DCT/선형 역복원/학습 디코더를 없애지 않습니다.

## 라벨 셔플 대조

무작위 라벨은 증강한 개별 행마다 다시 부여하지 않습니다. 학습 원본 결절의 source_id 단위로 고정 순열을 만들고 그 원본의 모든 사본에 같은 셔플 라벨을 적용합니다. 원본별 초기 라벨이 모순되면 중단합니다. 학습 원본 단위 순열은 원본 라벨 개수를 보존하지만, 사본 수가 서로 달라 증강 후 행별 클래스 비율까지 같아지는 것은 아니므로 두 분포를 따로 기록합니다.

주실험 학습·검증·시험의 정답은 바꾸지 않습니다. 셔플은 별도 진단이며 주실험의 모델·강도·분할을 선택하는 데 사용하지 않습니다.

## 화면에서 구분할 평가 집합

| 선택 | 원본 결절 수 또는 생성 행수 | 화면 연결 |
|---|---:|---|
| 원본 시험 | 873 | 원본 분류·복원·연결·멤버십 |
| 고정 증강 시험 | 2,000 | 생성 시험의 분류·복원·연결·멤버십 |
| 고정 균형 검증 | 2,000 | 모델 선정과 공격 선정에 사용한 검증. 없는 연결·멤버십은 미측정 |
| 원본 검증 | 937 | 원본 검증 분류·복원. 없는 연결·멤버십은 미측정 |

연결 평가는 현재 층별 float 특징의 닫힌 후보 집합 비교이며 FP16·INT8 복원 공격 선택과 별도입니다. 멤버십 역시 현재 분류 출력 기반 공격입니다. 정밀도 선택만으로 이 두 지표를 해당 전송 정밀도에서 새로 측정한 것처럼 표시하지 않습니다. 외부 코호트에 내부 증강 시험이나 검증을 대입하지 않습니다.

원래 다크/라이트, 왼쪽 메뉴, 그래프·툴팁·사진 설명 디자인은 유지합니다. 측정하지 않은 조합은 다른 집합 값으로 대체하지 않고 미측정으로 표시합니다.

## 검증 범위

발견 경로에 대한 작은 합성 CPU·API 검사를 먼저 수행하고 실제 변경 소스·로그를 결합합니다. 기존 자료·Rust 등의 변경없는 검사는 반복하지 않습니다. 장기 GPU 실험, 실제 의료영상의 원본 복원 성능, 모든 공격에 대한 프라이버시 보장은 이 코드 수정 검사와 별도입니다. 12차는 계속 유지하고 17차 정식 실행은 아직 시작하지 않습니다.
