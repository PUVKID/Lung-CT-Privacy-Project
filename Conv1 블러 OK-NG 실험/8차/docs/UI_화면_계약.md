# 8차 화면과 결과 연결 계약

화면 제목은 **폐 CT 강도별 학습과 복원 저항 실험·8차**입니다. 기존 7차의 단일 모델 실험과 서버를 수정하지 않고 별도 차수에 구현했습니다.

| 선택한 강도의 단계 | 화면에 표시할 값 | 완료 경계 |
|---|---|---|
| 새 100회 학습 중 | 해당 강도의 학습·검증 곡선, 실제 회차·학습률 | 다른 강도의 기록을 곡선이나 수치로 대신 표시하지 않음 |
| 분류 평가 완료·점수 대기 | 분류 정확도·정답수/시험분모·AUC·손실 | 점수는 미측정이며 강도 전체가 완료된 것으로 표시하지 않음 |
| 원본 후보 공격·점수 완료 | 정확도와 100점 점수, 각 원값·분모·분포 | 두 결과와 선정 체크포인트·입력·소스가 검증된 뒤 완료 |
| 점수 계산 또는 결합 오류 | 확인된 분류 성적과 명시적 점수 오류 | 빈 점수를 0이나 100으로 채우지 않음 |

강도 0·1·2·4·8·16·32·64·128·256은 같은 로컬 초기 가중치에서 각각 새로 학습합니다.

각 강도의 100회 학습 뒤 최저 raw validation loss 모델을 선정하고 분류와 점수를 측정합니다.

시험 수치로 모델이나 강도를 선정하지 않습니다.

같은 첫 합성 곱과 같은 강도는 후 단 학습이 달라도 같은 특징을 만들 수 있습니다.

## 점수 읽기

**분류 정확도**와 **원본 찾기·복원 저항 점수(100점)**를 나란히 표시합니다.

점수는 정해진 원본 후보 공격에서 측정한 연구용 값이며, 높을수록 이 공격에서 되찾기 어렵다는 뜻입니다. gallery-residual-v1을 사용합니다.

공격자는 원영상 후보 모음과 인코더·블러·전처리를 알고 있으며, 정확 특징 바이트 사전 공격을 포함합니다. gallery가 없는 복원이나 환자 재식별 방어로 확대하지 않습니다.

요약은 소수 첫째 자리 반올림이며 저장 원값을 바꾸지 않습니다.

실측 0점은 0.0/100으로 표시하고 대기·오류와 구분합니다.

정확도의 원 비율·정답 수/분모와 점수 원값·G·T_attack·T_prior·동점 분할 원본 찾기 비율·정확 반환 그룹 수·잔여 분포를 펼쳐 확인합니다.

시험 영상 수와 픽셀 구별 그룹 수는 다른 분모입니다.

표준 지표·보호 확률·차 등 프라이버시 보장을 뜻하지 않으며 문헌상 신규성·독창성은 검증되지 않았습니다.

## 조회와 인증 경계

| 조회 | 읽는 검증 자료 | 공개 응답에서 제외 |
|---|---|---|
| 상태 | 현재 8차 runtime 상태와 현재 소스의 실행 식별자 | 원본 경로·운영 오류 원문·인증 값 |
| 강도 결과 | 해당 강도의 history/selection/metrics/privacy, 체크포인트와 입력·소스 연결 | 원영상별 목록·예측 CSV·그룹별 원자료 경로 |
| 전체 그림 목록 | 완료 강도마다 18장, 총 180장 index와 각 강도의 모델·분류·점수 | 실제 원본 경로 |
| 그림 한 장 | 공통 index/소스/실행과 요청 강도의 18장 묶음·대상 PNG SHA | 무관한 다른 강도의 파일, 임의 경로 |

기존 루프백 Host 검사·세션 cookie의 HttpOnly/SameSite =Strict·고정 asset allowlist·읽기 전용 경로·응답 no-store·CSP를 유지합니다. 요청 간 검증 캐시는 사용하지 않습니다. 학습 서버나 실제 연구 결과를 이 화면 검사에서 기동·생성하지 않습니다.

## 화면 검증 범위

실측 0점·강도 변경 시 곡선/정확도/점수의 종속 전환·새 실행 시 이전 결과 제거는 Node VM의 실제 app.js 실행으로 검사합니다. HTTP API는 합성 파일과 임시 루프백 서버로 인증·입력·모델·점수·PNG 변조 경계를 검사합니다. 라이트/다크·모션 제어와 나눔 고딕 Bold700을 유지합니다.

실제 브라우저 화면·hover/focus·작은 화면 렌더링은 미검증이며 Node/API 검사로 정상이라고 확대하지 않습니다. 합성 검사는 실제 CT 공격 결과나 학습 완료가 아닙니다.
