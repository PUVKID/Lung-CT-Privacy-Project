**PowerShell에서 프로젝트 1차 폴더를 작업 디렉터리로 열고 전용 환경을 사용합니다.** 이미 실행 중인 학습이 있는지 먼저 확인하세요. 각 명령은 실제 상태 파일을 갱신하므로 진행 중에는 준비나 연결 검사도 중복 실행하지 마세요.

```powershell
.\.venv\Scripts\python.exe run_training.py prepare
.\.venv\Scripts\python.exe run_training.py smoke --device cuda
.\.venv\Scripts\python.exe run_training.py train --device cuda
```

`prepare`는 자료를 확인하고 분할을 기록합니다. `smoke`는 64 픽셀 난수 입력을 사용하는 연결 검사이며 연구 결과가 아닙니다. `train`은 config의 10개 sigma를 순서대로 학습합니다. GPU나 사전학습 가중치를 이용할 수 없는 경우 오류를 확인해야 합니다.

별도 PowerShell에서 `.\.venv\Scripts\python.exe dashboard.py`로 대시보드를 시작합니다. 생성된 로컬 접속 주소는 `work/server.json`에서 확인하며 토큰이 포함되므로 공유하거나 공개하지 마세요. 서버 종료는 해당 터미널에서 Ctrl+C를 사용합니다.

`실행_모니터링.ipynb`는 프로젝트 1차 폴더를 작업 디렉터리로 열고 전용 `.venv` 커널을 선택해 순서대로 실행합니다. `work/runtime/status.json`과 `work/results`를 읽고 사용 가능한 학습 이력을 그래프로 표시하며 학습을 시작하지 않습니다. 파일이 없으면 대기 상태를 표시합니다.

환자 ID가 없는 영상 단위 결과는 환자 독립적인 임상 성능을 나타내지 않습니다. 원본 영상·manifest·체크포인트·런타임 및 접속 정보는 공개하지 않습니다.

새 환경 재구성 시 Python3.12로 .venv를 만든 뒤 torch/torchvision은 https://download.pytorch.org/whl/cu128 공식 인덱스에서 requirements의 지정버전을 먼저 설치하고 나머지 requirements를 설치합니다. 공개본에서는 config.example.json을 config.json으로 복사하고 자체 데이터 경로를 지정해야 합니다. 이 컴퓨터의 원본 데이터나 기존 .venv를 공개 저장소에서 제공하지 않습니다.
