**폐 CT 영상에서 양성·정상을 OK(0), 악성을 NG(1)로 분류하고 첫 합성곱 특징에 10단계 블러를 적용하는 로컬 예비실험입니다.** 원본 1,097장 중 양성 120장·정상 416장·악성 561장입니다.

매 학습 회차(epoch)에 클래스당 5,000개를 원본 학습 영상의 반복 표본과 온라인 증강으로 구성합니다. 이는 독립 영상이나 환자 5,000명을 의미하지 않습니다.

환자 식별자가 없어 영상 단위 분할입니다. 바이트와 회색조 픽셀이 완전히 같은 영상은 같은 분할에 묶지만 동일 환자의 다른 영상이나 유사 영상의 분리 여부는 확인할 수 없습니다. 따라서 환자 독립성 또는 임상 성능을 주장할 수 없습니다.

초기 연속 배치에서 FP16 기울기 오버플로가 관측되어 실제 512픽셀 입력으로 재현했습니다. BF16을 명시하도록 수정한 뒤 실제 학습이 진행 중입니다. 오류 검사는 유지하며 아직 전체 학습 성능을 확정하지 않습니다.

원본 의료영상, 경로가 포함된 manifest, 모델 체크포인트, 접근 토큰, 개인 지침과 원본 노트북은 공개하지 않습니다. 실험 결과는 실제 저장된 결과로만 확인하며 아직 관측하지 않은 성능을 기재하지 않습니다.
