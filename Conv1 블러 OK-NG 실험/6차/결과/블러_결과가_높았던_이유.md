# 블러 결과가 높았던 이유

**블러는 실제로 적용됐습니다. 가장 중요한 차이는 블러 강도마다 별도 모델을 학습했다는 점입니다.**

기존 5차의 원본·모델·결과를 보존하고, 6차에서 실제 추가 실험을 진행했습니다. 같은 시험 영상 164장을 다시 사용한 탐색적 진단이며, 새로운 환자에 대한 독립 성능 검증은 아닙니다.

| 블러 강도 | 해당 강도에서 별도로 학습한 모델·5차 | 블러 없이 배운 같은 모델에 블러만 추가·6차 |
|---|---:|---:|
| 0 | 100.0%·164/164장 | 100.0%·164/164장 |
| 4 | 100.0%·164/164장 | 50.0%·82/164장 |
| 16 | 97.6%·160/164장 | 48.8%·80/164장 |
| 64 | 79.9%·131/164장 | 48.8%·80/164장 |
| 256 | 53.7%·88/164장 | 48.8%·80/164장 |

기존 실험은 ‘같은 모델이 블러를 견디는가’보다 ‘블러가 있는 특징으로 다시 학습하면 얼마나 분류할 수 있는가’를 측정했습니다. 추가 실험에서 고정 모델의 성능이 크게 떨어진 관측은 이 두 질문을 구분해야 함을 보여 줍니다.

강도 0·4·16·256의 기존 선택 모델을 실제 CT에 다시 적용한 결과, 예측 확률의 최대 차이는 모두 0이었습니다. 강도 64의 위 기존 모델 수치는 5차 저장 결과이며, 이번 재추론 4 조건에는 포함되지 않습니다. 모델 선택 기준은 시험 정확도가 아니라 검증 손실입니다.

| 추가 검사 | 실제 관측 | 의미와 한계 |
|---|---|---|
| 블러 수학 대조 | 독립 SciPy 대조 CPU·CUDA 각각 70 조건 통과 | 블러가 적용되지 않았다는 설명과 맞지 않습니다. |
| 실제 특징의 변화 | 강도 256의 공간 변화 에너지 평균 잔존 비 약 0.0001219% | 공간 세부는 크게 줄었고, 채널 평균은 수치 오차 범위에서 보존됐습니다. |
| 특징 평균 64개만 분류 | 70.7%·116/164장 | 남은 평균 정보에도 분류 신호가 있지만, 이것만으로 100%를 설명하지는 못합니다. |
| 사진 전체 밝기 분포 45개 | 97.6%·160/164장 | 원영상의 단순 분포에도 라벨과 관련된 단서가 있습니다. |
| 외곽 5% 통계 45개 | 94.5%·155/164장 | 바깥 영역에도 단서가 있습니다.<br>원래 신경망이 이를 사용했다고 확정한 것은 아닙니다. |
| 가장 비슷한 학습 영상의 답을 사용 | 100.0%·164/164장 | 현재 분할은 영상 유사도만으로도 높은 성능이 나오는 시험입니다. |
| 학습 정답을 섞은 대조 10회 | 평균 50.2% | 같은 저차원 구조에서 정답 관계를 깨면 평균 성능이 낮아졌습니다. |
| 분할 재검사 | 파일 해시·픽셀·고정 유사 그룹의 교차 겹침 0 | 환자 ID가 없으므로 환자 독립성을 보장하지 않습니다. |

블러는 모든 정보를 지우는 연산이 아닙니다. 강도에 맞춰 학습하면 남아 있는 정보를 사용할 수 있습니다. 다만 단순 밝기나 테두리의 높은 분류력, 가까운 영상의 높은 분류력은 기존 신경망의 유일한 판단 원인을 증명하지 않습니다. 같은 환자나 촬영기관의 영향이라고 확정할 자료도 없습니다.

**현재 결과는 블러 특징을 이용한 적응 분류의 탐색 결과로 해석할 수 있지만, 임상 일반화·환자 독립성·프라이버시 달성을 입증하지는 않습니다.** 정식 후속 평가에는 환자 ID에 따른 분리, 기관·외부 자료 평가, 병변 영역과 비병변 영역의 대조가 필요합니다.

이번 시험 점수로 블러 강도나 임계값을 선택하지 않았습니다.

백분율은 소수 첫째 자리 반올림입니다. 원비율·혼동 행렬·예측 값은 비공개 원본 JSON과 CSV에 보존했습니다. 독립 검증의 완료 여부는 별도 검토 문과 중앙 영수증으로 확인합니다.
