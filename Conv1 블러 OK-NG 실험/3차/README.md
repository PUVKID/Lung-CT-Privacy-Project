# 폐 CT 특징맵 시각화 · 공개 코드 3차

학습 2차에서 완료한 블러 조건의 특징맵을 범주·단계별로 저장하고 대시보드에서 살펴보는 소프트웨어 변경 묶음입니다. 학습 3차를 새로 시작한 결과가 아닙니다.

한 조건은 양성·악성·정상 대표 CT 3장과 입력부터 마지막 잔차 블록 묶음까지 6개 단계로 구성해 PNG 18개를 저장합니다. 원본 기준을 포함한 10조건이 모두 끝나면 180개입니다.

입력 영상은 1패널, 특징맵은 평균·최댓값·개별 채널 8개의 10패널이며 사진 아래에 추출 위치와 해석을 설명합니다.

코드 폴더의 src·학습 실행기·설정 예제와 의존성은 앞선 공개 2차와 같습니다. 실제 학습 소스·설정·체크포인트를 바꾸지 않고 별도 CPU 저장 도구가 완료한 결과만 읽습니다. 원본 의료영상·특징맵 PNG·영상별 목록·가중치·운영 기록은 포함하지 않습니다. 환자 ID가 없어 영상 단위 예비실험이며 특징의 색을 병변 위치나 프라이버시 보장으로 해석하지 않습니다.
