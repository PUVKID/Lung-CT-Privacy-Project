# 🔎 블러 강도별 결과 선택 · 공개 코드 4차

강도 버튼을 고르면 📷 사진·📈 학습 곡선·📊 시험 결과가 같은 강도로 바뀝니다. 상단의 마지막 실행 상태와 선택한 결과를 나눠 표시하고 자동 갱신에도 선택을 유지합니다.

실제 학습 2차의 대시보드 로컬 수리 3차를 공개 코드 4차로 보존한 사본입니다. 새 학습 차수를 시작하지 않습니다. 학습 코드·설정·가중치와 이전 공개 1~3차를 보존합니다. 누락·미완료·다른 실행의 결과는 미측정 또는 대기로 표시하고 직전 시험 수치를 재사용하지 않습니다.
