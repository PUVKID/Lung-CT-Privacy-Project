**완료한 학습 조건의 최적 체크포인트를 CPU에서 읽습니다.** 참고 자료는 10조건·3원본 범주·6단계의 PNG 상대 경로 180개가 있는 로컬 폴더여야 합니다. 출력 폴더는 미리 준비한 별도 일반 폴더를 지정합니다. 원본 학습 폴더나 참고 자료 폴더를 출력으로 지정하지 않습니다.

```powershell
python -B -X utf8 "생성 도구/단계별_특징맵_저장.py" --experiment-root "학습 폴더" --output-root "특징맵 출력 폴더" --reference-root "참고 특징맵 폴더" --run-id "실제 실행 식별자" --once
```

계속 확인하려면 --once 대신 --watch를 사용합니다. 기존 학습 환경의 torch·torchvision·NumPy·Matplotlib·Pillow와 학습 폴더의 src 코드, 글꼴 파일이 필요합니다. 학습 분할 목록과 완료 지표·최적 체크포인트를 확인한 조건만 내보냅니다. 원본 CT와 체크포인트의 해시가 맞지 않거나 같은 실행으로 확인되지 않으면 실패를 보고합니다. 원본 코드의 pickle 체크포인트를 읽으므로 자신이 생성하고 검증한 로컬 체크포인트만 사용합니다.

대시보드의 기본 저장 위치는 실행 폴더의 상위에 있는 블러 강도별 대표 특징맵/2차입니다. 출력 위치를 그 경로에 맞추면 대시보드가 export_index_private.json과 18장 묶음을 읽습니다. 공개 3차 코드만 내려받아 기존 학습을 새로 실행하면 학습 코드 해시로 실행 식별자가 달라질 수 있으므로, 진행 중 학습 폴더를 공개 사본으로 교체하지 않습니다.

실제 PNG·영상별 목록·체크포인트·비공개 색인은 저장소에 추가하지 않습니다. 모든 조건이 끝나기 전에는 전체 180개가 생성되었다고 해석하지 않습니다.
