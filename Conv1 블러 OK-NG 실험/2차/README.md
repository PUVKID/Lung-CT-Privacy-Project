# 폐 CT 특징 블러 실험 · 2차

고정된 첫 합성곱의 특징에 블러를 적용한 뒤 양성·정상을 OK, 악성을 NG로 분류합니다. 원본을 분할한 뒤 학습에만 클래스당 5000개 온라인 표본을 구성합니다. 원본 환자 ID가 없어 영상 단위 예비실험입니다.

1차의 초기 검증 포화와 손실 계산을 감사한 뒤 평가 수치, 유사 영상 분할, 학습 예산·종료 기준을 보완했습니다. 1차의 결과·가중치는 보존하며 2차는 ImageNet 초기값으로 새로 시작합니다. 원본 노트북과 프레임워크·가중치·전처리가 달라 수치상 재현은 아닙니다.

| 항목 | 1차 | 2차 |
|---|---|---|
| 최대 에폭 | 35 | 100 |
| 조기 종료 | 검증 손실 7회 정체 | 의미 있는 개선 15회 정체 |
| 개선 기준 | 엄격한 감소 | 종료 판단은 절대 0.0001, 체크포인트는 실제 최소 손실 |
| 최적화 | Adam, 0.00008 | AdamW, 0.00003, 가중치 감쇠 0.0001 |
| 학습률 조절 | 없음 | 검증 미개선 4회를 허용한 뒤 다음 미개선에서 0.5배, 최저 0.000001 |
| 배치 | 2 | 8 |
| 학습 표본 | 클래스당 5000/epoch | 동일 |
| 분할 | 바이트·픽셀 완전 중복 그룹 | 완전 중복 + 고정 64px RMSE≤5 유사 그룹 |
| 평가 | 혼합 정밀도·확률 점수 | FP32 추론·FP64 안정 손실·로짓 순위 점수 |

최대 100회는 학습 상한이며 100회를 강제로 반복하지 않습니다. 에폭당 가중치 갱신 수가 배치 크기에 따라 달라지므로 두 차수의 에폭만 비교하지 않습니다. 유사 그룹은 환자 그룹이 아닙니다. 소스별 촬영·압축 차이와 같은 환자의 다른 영상은 여전히 성능을 부풀릴 수 있습니다.
