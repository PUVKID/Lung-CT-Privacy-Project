# 첨부 원본·1차와 2차의 차이

제공 노트북은 TensorFlow/Keras ImageNet ResNet50에서 `conv1_conv`를 고정 Edge로 분리하고 DCT 기반 블러 뒤 Cloud의 마지막 잔차 블록과 분류 헤드를 학습합니다. 회색조 영상을 512×512로 맞춰 3채널로 복제하고 Keras의 BGR 평균 차감 전처리를 사용합니다. 환자 ID가 있는 입력을 요구하며 환자 단위 10% 시험 분리와 7-fold, 10개 sigma의 adaptive 분류, sigma 0 고정 대조군, 동일 영상 매칭 및 복원 공격을 포함합니다. 원본 기본값은 배치 2, 최대 35 epoch, patience 7, 분류 학습률 0.00008입니다.

1차부터 사용한 이식 코드는 PyTorch/torchvision ResNet50 V1.5와 ImageNet1K V1 가중치를 사용합니다. 구조의 stride와 가중치가 Keras와 다르며 회색조 3채널을 0~1로 변환한 뒤 RGB 평균·표준편차로 정규화합니다. 첫 합성곱과 모든 배치정규화를 고정하고 마지막 layer4의 비배치정규화 가중치와 128 유닛 분류 헤드를 학습합니다. sigma는 특징맵 픽셀 단위이며 값은 0, 1, 2, 4, 8, 16, 32, 64, 128, 256입니다. 원본과 수치적으로 동일한 재현이 아닙니다.

1차 기본 설정은 영상 중복 그룹 기준 학습·검증·시험 약 70:15:15, 512 픽셀, 배치 2, 최대 35 epoch, patience 7, 학습률 0.00008입니다. 각 학습 epoch에는 클래스별 5,000개를 반복 추출하고 좌우 반전·명암·밝기 변화를 적용합니다. 검증과 시험에는 증강하지 않습니다. 완전 중복만 같은 분할에 묶으며 환자 ID가 없으므로 환자 독립성을 검증하지 못합니다.

원본의 환자 7-fold, fixed 대조군, 영상 매칭, 복원 공격 및 프라이버시 임계점 선택은 이번 단일 holdout 예비실험에 구현되지 않았습니다. 시험 결과를 사용해 sigma나 임계값을 선택하지 않습니다. 원본 노트북은 변경 없이 로컬 사본으로 보존하며 저작권 확인 전 공개하지 않습니다.

현재 CUDA 학습 정밀도는 BF16을 명시하며 FP16을 선택한 경우에만 GradScaler를 사용합니다. 비유한 손실/기울기 검사는 유지합니다. 연속 20배치와 검증 161장 연결 검증은 최종 시험 성능이 아닙니다. 재개 시 CUDA RNG state는 CPU ByteTensor로 복구합니다. [PyTorch 혼합 정밀도 공식 문서](https://docs.pytorch.org/docs/stable/amp.html)를 함께 참고했습니다.

실시간 상태 파일은 Windows에서 읽기 핸들의 삭제 공유와 ReplaceFileW를 결합해 원자적으로 교체합니다. 짧은 공유 위반은 제한된 횟수만 재시도하고 계속되는 오류를 보고합니다. 이는 모델 학습의 실패를 숨기는 분기가 아닙니다. [Microsoft 파일 교체 문서](https://learn.microsoft.com/en-us/windows/win32/fileio/moving-and-replacing-files)를 참고했습니다.

## 2차 보완

첨부 원본과의 구조·프레임워크 차이는 위와 같습니다. 2차는 1차의 최대 35회 설정을 재검토하여 최대 100회·정체 15회로 조정했습니다. 검증 손실이 절대 0.0001 초과 개선되어야 정체 횟수를 초기화하지만, 최적 체크포인트는 이 기준과 별도로 실제 최소 손실로 보존합니다. 학습률 감소는 검증 미개선 4회를 허용한 뒤 다음 미개선에서 적용하며, 감소율 0.5, 최저 0.000001입니다. AdamW 학습률 0.00003과 가중치 감쇠 0.0001을 사용하며 배치 8에서 각 회차 1250회 가중치를 갱신합니다. 클래스당 5000개 학습 표본은 유지합니다.

고정 64px 회색조의 8bit RMSE≤5인 쌍과 완전 중복의 연결 성분을 같은 분할에 묶습니다. 기준은 검증 성능을 높이거나 낮추기 위한 조절값이 아니며 label을 보지 않고 계산합니다. 유사 그룹과 환자 그룹은 다릅니다. 임의 환자 ID를 생성하지 않습니다.

평가에서는 FP32 추론 뒤 signed-softplus FP64 손실을 사용하고, AUC·AP는 sigmoid 포화 이전 로짓 순위로 계산합니다. 확률은 별도로 저장합니다. 수치적 손실 0을 완벽한 임상 분류라는 뜻으로 사용하지 않습니다. 1차 best 모델은 이런 정밀도 감사에서도 검증 정확도·AUC1.0이 유지됐으므로 평가 수치 수리가 높은 검증 성능의 원인을 모두 해결했다는 주장은 하지 않습니다.

양성·정상·악성 원본 범주별 결과도 남깁니다. 단일 라벨 범주에서 AUC를 정의할 수 없으면 null로 표시하며 클래스별 오류와 전체 이진 분류를 구분합니다. checkpoint에는 optimizer·scheduler·의미 있는 개선 기준·최적 회차·RNG를 포함하고 원본/코드/설정 식별자가 다른 실행은 재사용하지 않습니다.
