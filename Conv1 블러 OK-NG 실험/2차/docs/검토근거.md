# 2차 검토 근거

## 확인된 문제와 한계

1차에서는 epoch마다 OK·NG를 각각 5000개씩 학습했으며 배치 2로 5000번의 optimizer update가 발생했다. 따라서 epoch 숫자만으로 학습량을 비교하면 안 된다. 원본의 최대 35회 설정을 충분성 검토 없이 그대로 사용했다.

1차 평가에서는 BF16 로짓의 sigmoid를 먼저 계산한 뒤 FP32로 바꿨다. 확률의 양자화와 동점 위험을 줄이기 위해 평가 정밀도를 높일 필요가 있다. 기존 정확도 1.0이 이 문제 때문이라고 확정하지 않는다.

기존 train769/validation161을 이용한 별도 감사에서 64px 회색조 1-NN 검증 정확도 159/161, 영상 크기·JPEG 파일 크기만 사용한 분류 정확도 156/161을 관측했다. 시험셋은 이 감사 분류기의 학습·평가에 사용하지 않았다. 이는 유사 영상 및 소스 차이의 영향을 의심할 근거이며 실제 ResNet이 파일 크기를 입력받았다는 뜻은 아니다. 실제 모델은 회색조 픽셀만 입력받는다. 파일 번호의 인접성을 환자 ID로 해석하지 않는다.

## 평가 원칙

유사도 그룹은 환자 그룹이 아니다. 원본 환자 ID 없이 환자 독립성·임상 성능을 주장하지 않는다. 라벨과 성능에 맞춰 유사도 임계값을 조정하지 않는다. 같은 원본에서 증강한 영상을 별도 독립 영상으로 세지 않는다. 검증·시험은 증강하지 않는다. 완전 중복뿐 아니라 사전 명시한 보수적 유사 기준의 그룹도 분할 사이에 섞이지 않게 검증한다.

최대 에폭은 학습 예산의 상한이다. 실제 종료는 검증 손실의 의미 있는 개선·정체에 따라 결정하며 최적 모델은 검증 지표로 선택한다. 시험 결과를 이용해 학습률·sigma·종료 조건을 고르지 않는다.

## 공식 참고

- [PyTorch ReduceLROnPlateau](https://docs.pytorch.org/docs/stable/generated/torch.optim.lr_scheduler.ReduceLROnPlateau.html): 검증 정체에 따른 학습률 감소.
- [PyTorch AdamW](https://docs.pytorch.org/docs/stable/generated/torch.optim.AdamW.html): 가중치 감쇠를 포함한 최적화.
- [scikit-learn 교차검증](https://scikit-learn.org/stable/modules/cross_validation.html): 상관된 표본의 그룹 분리와 시험셋 보존.

세부 실행 설정과 검사 결과는 조사 완료 뒤 실행 문서와 변경 기록에 확정한다. 특정 epoch·학습률이 보편적 최적값이라는 뜻은 아니다.

2차는 분할·배치·학습률·최적화·평가 계산을 함께 보완한 후속 예비실험입니다. 두 차수의 수치 차이를 에폭 증가 하나의 효과나 공정한 단일 요인 절제 실험으로 주장하지 않습니다. 학습 중간에 확인한 검증 정보가 있으므로 완전히 사전 등록된 독립 연구로 표현하지 않습니다. 최종 환자 독립성 검증에는 실제 환자 ID와 별도 출처 데이터가 필요합니다.
