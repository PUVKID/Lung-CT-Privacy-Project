**Python 3.12 환경을 준비하고 requirements.txt의 버전을 설치합니다.** torch와 torchvision은 CUDA 12.8 공식 패키지 인덱스를 사용합니다. 기존 환경을 사용하는 경우 실제 패키지 버전과 CUDA·BF16 지원을 확인합니다. 폴더 연결이나 바로가기는 필요하지 않습니다.

공개본에서는 config.example.json을 config.json으로 복사한 뒤 자체 데이터 경로를 설정합니다. 이미지 원본이나 모델 가중치는 저장소에 포함하지 않습니다.

```powershell
python -B -X utf8 run_training.py prepare
python -B -X utf8 run_training.py smoke --device cuda
python -B -X utf8 run_training.py train --device cuda
```

프로젝트 2차를 작업 디렉터리로 사용합니다. 준비와 smoke는 상태 파일을 갱신하므로 실제 학습 도중 중복 실행하지 않습니다. smoke는 작은 난수 입력 연결 검사이며 실험 성능이 아닙니다. 실제 학습은 config의 10개 sigma를 순서대로 실행합니다.

대시보드는 별도 프로세스에서 `python -B -X utf8 dashboard.py`로 시작합니다. 로컬 접속 URL은 work/server.json에 저장되며 토큰이 포함되므로 공유하지 않습니다. 최대 에폭과 현재 학습 회차, 현재 학습률, 의미 있는 개선 없이 지난 회차, 최적 회차와 가중치 갱신 횟수를 구분해 표시합니다. 흰색 기본 테마·다크/라이트 전환·3D 모형·움직임 제어를 제공합니다.

2차는 새 run_id와 ImageNet 초기값으로 시작하며 1차 가중치를 불러오지 않습니다. 동일한 2차 소스·자료·설정에서 중단된 실행만 마지막 완료 회차의 optimizer·scheduler·RNG 상태로 재개합니다. 미완료 회차는 처음부터 다시 수행하므로 중단된 배치까지 정확히 이어가는 기능은 아닙니다.

시험셋은 학습률·블러 강도·임계값을 정하는 데 사용하지 않습니다. 유사도 그룹 분리는 환자 독립성을 보장하지 않습니다. 학습이 끝났다는 표시는 실제 큐가 완료된 경우에만 사용합니다.
